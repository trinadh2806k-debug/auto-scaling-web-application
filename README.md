# Cloud Auto Scaling Dashboard

## Project Type
Cloud Computing Web Application / Simulation

## Description
A browser-based cloud auto scaling dashboard that simulates monitoring cloud traffic, CPU usage, response time, and virtual machine instances.

## Main Features
- User registration and login
- Logout and profile display
- Light/Dark mode
- Traffic simulation
- CPU monitoring
- Automatic scale-out and scale-in
- Manual instance scaling
- Minimum/maximum instance configuration
- Target CPU policy
- Response modes
- Health check simulation
- Scaling alerts
- Activity log
- LocalStorage data persistence
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Project Structure
cloud-auto-scaling-dashboard/
│
├── index.html

## How to Run
1. Open the folder in Visual Studio Code.
2. Open `index.html`.
3. Use Live Server in VS Code, or open the HTML file directly in a browser.
4. Create an account using Sign Up.
5. Login and test the dashboard.

## Important Note
This is a front-end simulation of cloud auto scaling. It does not create real AWS/Azure/GCP virtual machines. A real cloud deployment would require a backend and cloud APIs.
